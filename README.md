# Weed Rating

A small installable web app to rate what you buy on taste, smell, price and THC, so you can always compare.

- Rate taste, smell and price from 1 to 10 in steps of 0.1
- Add THC %, price per gram, coffeeshop, purchase date, notes and up to 6 photos
- Tabs for Indica, Sativa and Hybrid, ranked by total score within each tab
- Compare up to 3 strains side by side
- Works offline once opened and can be installed from Chrome ("Install app")
- Everything is stored on your own device (IndexedDB), nothing is uploaded

No build step: open `index.html` or host these files as-is (for example with GitHub Pages).
